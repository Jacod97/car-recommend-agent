# 수집 데이터

## 공통

차명·모델·트림, 차량번호, 연식, 최초등록, 주행거리, 판매가, 연료, 변속기, 배기량, 색상, 옵션, 사고 여부, 판매 상태

케이카를 뺀 세 곳은 보험 사고 내역(날짜·수리비), 소유자 변경, 침수·전손·도난, 렌트·영업 이력도 공통이다.

## 사이트에만 있는 것

| 사이트 | 데이터 |
|---|---|
| 현대 | 신차가, 할인 전 가격, 할인·행사 표시, 보험 정보 없는 기간 |
| 기아 | 제원(출력·연비·크기·무게), 구매 부대비용(탁송·이전비), 남은 보증, 상품화 작업 |
| 헤이딜러 | 신차가, 이전 가격, 제원(출력·연비·크기), 타이어 상태, 외판 교환·도장 횟수, 정비 기록·리콜, 조회 수 |
| 케이카 | 차종, 승차 인원, 월 할부 예시 |

## 이슈

- 엔카: robots.txt로 수집 금지, crawler 차단 중. 공개 API 없음. 수집 안 함
- 케이카: 상세는 robots.txt로 금지, 상세에 이전 소유자 주소·나이·성별이 들어 있음. 목록만 수집
